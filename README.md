# RUSHIFIC V2.6

Static one-page creator website. Built with plain HTML, CSS and JavaScript so it can be hosted free on GitHub Pages.

## Edit text and links
Open `script.js`.

- `SITE.copy` contains the visible website text.
- `SITE.links` contains the platform URLs.

Replace the `#` placeholders when the official links are ready.

## Main asset
`assets/eggface.png` is the current RUSHIFIC egg asset.

## Run locally
Open `index.html` in a browser, or use any simple local static server.
