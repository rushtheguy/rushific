# RUSHIFIC V2.7

Static one-page creator website for RUSHIFIC, built with plain HTML, CSS and JavaScript for GitHub Pages.

## Edit text and links

Open `script.js`.

- `SITE.copy` contains the visible website text.
- `SITE.links` contains the platform URLs.

## Assets

- `assets/eggface.png` — RUSHIFIC egg mascot and favicon.
- `assets/clown-discord.jpg` — Discord section artwork.

## Hosting

This package is designed to replace the existing files in the GitHub repository. The custom domain/DNS configuration does not need to be repeated when only the website files are changed. GitHub Pages will deploy the updated files from the repository.

## Run locally

Open `index.html` in a browser, or use any simple local static server.
